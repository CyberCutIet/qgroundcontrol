# QGC FPV — наша рабочая версия

Рабочая ветка: **fpv-modified** в `CyberCutIet/qgroundcontrol`. Исходная проверенная основа — upstream-коммит `4568b585648e8c6065cca6c650b52731c1d3baa3`. Основная ветка `master` остаётся копией оригинального QGC; её обновления не подмешиваются автоматически в проверенную сборку.

## Что перенесено

- Определение TX-12 и Pocket по имени, отдельные штатные значки, восстановление выбора TX-12 после переподключения.
- Встроенный мост Pocket на Linux: evdev, отдельный поток, UDP `10.10.10.13:7002`, 100 Гц, пакет `<16H`. Старый Python-мост сохранён в `bridge/` для справки; одновременно с встроенным мостом его запускать не следует.
- Вынос: RSSI/SNR RADXA из WFB JSON API `10.10.10.13:9001`.
- Ретранслятор: RSSI/SNR RPi из JSON v1, доставляемого RADXA на UDP 5800. Отправитель и systemd-unit находятся в [bridge/rpi-stats](bridge/rpi-stats/README.md).
- Packet Loss: оценка `100 × lost / (out + lost)` по `video_repiter rx` после FEC, окно 3 секунды, обновление интерфейса каждые 500 мс. Отчёты API могут приходить раз в секунду; промежуточные данные не выдумываются. Восстановленные FEC-пакеты не прибавляются к потерям. Служебные FEC-пакеты могут влиять на точность оценки.
- Исправление падения GStreamer при ошибке запуска UDP-видео: очистка указателей после освобождения pipeline и проверка источника отложенных ERROR/EOS.
- Исправления сборки и инструментов для путей с пробелами.

## Принятый вид панели

Порядок: **Вынос · Ретранслятор · Packet Loss · TX-12 · Pocket**. Заголовки жирные, подняты на половину строки. Блоки компактные, ширина `defaultFontPixelWidth × 13`. RSSI и SNR выровнены слева: `RSSI - 23 dBm`, `SNR - 20 dB`. Значок потерь и процент сгруппированы по центру.

Потери отображаются до десятых с округлением вверх: `0.01% → 0.1%`; настоящий ноль остаётся `0.0%`. Цвет и деления зависят от показанного значения:

| Потери | Цвет | Столбики |
|---|---|---|
| 0% | Зелёный | 4 |
| >0 и <5% | Салатовый | 4 |
| 5–<20% | Жёлтый | 3 |
| 20–<50% | Оранжевый | 2 |
| ≥50% | Красный | 1 |

Нет свежих данных — «—», не нулевые потери. Цвета RSSI зависят только от RSSI, границы −85/−75/−65/−55 dBm. Значки пультов отражают локальное подключение и работу управления, а не подтверждение радиодоставки.

## Сборка и запуск

Зависимости и общая инструкция: [документация QGC](../README.md), [инструменты](../tools/README.md). На используемом ноутбуке установлена Qt 6.11.1, сборка Debug с тестами:

```bash
python3 tools/configure.py -B build -t Debug --testing --qt-root "$HOME/Qt/6.11.1/gcc_64"
JOBS=4 just build
./run_qgc.sh
```

Команды выполняются из корня репозитория. Launcher запускает готовый бинарник и не компилирует программу. Уже работающий QGC нужно закрыть перед повторным запуском.

Видео-профиль: [profile/video.ini](profile/video.ini). Требуется локальный адрес `10.10.10.1`, UDP 5602, RTP/H.264. Профиль выбирает low-latency CPU-декодирование (`avdec_h264`, `videoconvert`, вывод QGC без синхронизации). На исходном ноутбуке профиль уже настроен; для другого компьютера после первого запуска и закрытия QGC:

```bash
python3 fpv/apply_video_profile.py --dry-run
python3 fpv/apply_video_profile.py
```

Скрипт сохраняет резервную копию INI и меняет только видеопрофиль. Полные настройки пользователя и калибровки в репозиторий не включены.

## Как получать обновления

`origin` — этот форк, `upstream` — `https://github.com/mavlink/qgroundcontrol.git`. Перед обновлением сохраняем проверенную сборку и создаём временную ветку от `fpv-modified`. Получаем изменения upstream, объединяем их в этой временной ветке, разрешаем конфликты, собираем и тестируем видео, управление и статистику. Только после проверки обновляем `fpv-modified`. Принудительное переписывание истории для обычного обновления не требуется.

Перенос в форк сохраняет проверенную основу и не является обновлением до текущего `master`.

## Проверки и ограничения

Профильные тесты: `WfbLinkStatusTest`, `RpiLinkStatusTest`, `DualJoystickIndicatorTest`, `ControlBridgeStatusTest`, `JoystickManagerTest`, `GStreamerTest`. Сервис RPi проверяется `python3 -m unittest discover -s fpv/bridge/rpi-stats -p 'test_*.py'`.

После переноса новая копия успешно собрана; все 6 профильных тестов и 5 Python-тестов прошли. Unit-прогон: 199/200, существующая ошибка BluetoothWorkerTest при выключенном адаптере. Полный lint не завершён из-за SSL-ошибки при установке TruffleHog. Готовность к стендовому тестированию не закрывает автоматически проблемы восстановления радио/видео после обрыва.

Этот репозиторий публичный. Логи стенда, снимки экрана, пароли, ключи WFB, личные INI и сборочные файлы сюда не включаются. Лицензии оригинального QGC сохранены в корне репозитория.
